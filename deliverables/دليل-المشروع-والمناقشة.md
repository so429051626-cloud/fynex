# دليل مشروع Code Café (للتسليم والمناقشة)

## 1. ما الذي ستسلّمه

| الملف | الوصف |
|---|---|
| `StudentName_StudentID.zip` | ملف المشروع المضغوط. **غيّر اسمه** إلى اسمك ورقمك الجامعي حسب طلب الجامعة، مثل: `Ahmad_Ali_202312345.zip` |
| `Code-Cafe-Explainer.mp4` | فيديو شرح جاهز (حوالي 11 دقيقة) بصوت عربي مولَّد آليًا وترجمة مكتوبة على الشاشة |
| `Code-Cafe-Explainer.srt` | ملف الترجمة نفسه بشكل منفصل (يمكن رفعه مع الفيديو على YouTube) |
| `نص-فيديو-الشرح.txt` | النص الكامل للفيديو مع التوقيت، لتقرأه بصوتك عند التسجيل |

> **مهم:** المطلوب في المشروع أن يكون الشرح **بصوتك** وأن تبدأ **باسمك ورقمك الجامعي**.
> الفيديو المرفق صوته مولَّد آليًا، وحقلا الاسم والرقم في بدايته فارغان.
> الأفضل أن تسجّل الفيديو بصوتك وأنت تقرأ من `نص-فيديو-الشرح.txt`. ويمكنك استخدام الفيديو المرفق كمرجع، أو أرسل لي اسمك ورقمك الجامعي فأضيفهما إلى شاشة البداية.

### محتوى ملف ZIP

```
Code-Cafe/
├── index.html        ← الصفحة الرئيسية
├── Reserve.html      ← صفحة حجز طاولة (نموذج)
├── Thanks.html       ← صفحة الشكر وتأكيد الحجز
├── images/           ← 20 صورة (شعار، أيقونة، مشروبات، أطعمة، أجواء المقهى)
├── media/            ← cafe-tour.mp4 (فيديو جولة 38 ثانية) و cafe-music.mp3 (موسيقى)
└── video link.txt    ← عنوان الفيديو ومكان فارغ لوضع الرابط الحقيقي
```

جميع الصور والوسائط **رسمتها وأنتجتها بنفسي من الصفر** (رسوم توضيحية وموسيقى أصلية)، فلا توجد مشكلة حقوق ملكية، ولا توجد أي روابط مكسورة.

## 2. شرح مختصر لكل ملف

### `index.html` – الصفحة الرئيسية
- **رأس الصفحة `<header>`**: صورة الشعار، واسم المقهى `<h1>`، والشعار النصي "حيث تلتقي القهوة بالبرمجة".
- **قائمة التنقل `<nav>`**: قائمة `<ul>` فيها روابط لأقسام الصفحة (`#about`، `#menu`…) ورابط لصفحة الحجز.
- **قسم الترحيب `#welcome`**: صورة كبيرة للمقهى، ونص ترحيبي، ورابط "احجز طاولتك الآن".
- **قسم من نحن `#about`**: نبذة عن المقهى وفكرته، وقائمة نقطية بالمميزات.
- **قسم القائمة `#menu`**: جدولان، الأول للمشروبات (6 أصناف) والثاني للأطعمة (4 أصناف)، ولكل صنف صورة واسم ووصف وسعر.
- **قسم الأجواء `#gallery`**: أربع صور داخل `<figure>` مع وصف `<figcaption>`، وفيديو `<video>`، وملف صوتي `<audio>`.
- **الأسئلة الشائعة `#faq`**: العنصر `<details>` الذي يفتح ويغلق بدون JavaScript.
- **التواصل `#contact`**: العنوان والهاتف والبريد داخل `<address>`، وجدول ساعات العمل، وقائمة مرقّمة `<ol>` لخطوات الحجز، ورابط واضح لصفحة الحجز.
- **التذييل `<footer>`**: حقوق النشر، وملاحظة أن البيانات افتراضية، ورابط العودة إلى الأعلى `#top`.

### `Reserve.html` – صفحة الحجز
- عنوان يوضح أن الصفحة للحجز، وملاحظة أن الحجز **تجريبي وغير متصل بخادم**.
- نموذج `<form action="Thanks.html" method="get">` مقسم إلى 3 مجموعات `<fieldset>`:
  1. البيانات الشخصية: الاسم (`text`)، البريد (`email`)، الهاتف (`tel` + `pattern`).
  2. تفاصيل الحجز: التاريخ (`date`)، الوقت (`time` + `min`/`max`)، عدد الأشخاص (`select`)، مكان الجلوس (`radio`).
  3. ملاحظات إضافية (`textarea`) ومربع موافقة (`checkbox`).
- زر الإرسال `submit` وزر المسح `reset`، ورابط العودة للرئيسية.

### `Thanks.html` – صفحة الشكر
- رسالة شكر، ورسالة تؤكد استلام النموذج **تجريبيًا**، وتوضيح أن البيانات تظهر في شريط العنوان بسبب `get`.
- رابط للعودة إلى الصفحة الرئيسية، ورابط للعودة إلى صفحة الحجز.

### `video link.txt`
عنوان الفيديو، وأماكن لاسمك ورقمك الجامعي، ومكان واضح لوضع **رابط الفيديو الحقيقي** بعد رفعه. لم أضع أي رابط مختلق.

## 3. كيف تشغّل الموقع

1. فك ضغط ملف ZIP.
2. افتح المجلد `Code-Cafe`.
3. انقر مرتين على `index.html`، فيفتح في المتصفح (Chrome أو Edge أو Firefox).
4. لا تحتاج إلى إنترنت ولا خادم ولا قاعدة بيانات.

## 4. كيف تختبر الموقع (نفّذتُ كل هذه الاختبارات وكلها ناجحة)

- [x] الروابط بين الصفحات الثلاث تعمل في كل الاتجاهات.
- [x] روابط الأقسام (`#about`، `#menu`، `#gallery`، `#contact`، `#top`) تنقل إلى القسم الصحيح.
- [x] جميع الصور (17 في الرئيسية، و1 في الحجز، و2 في الشكر) تظهر، ولكل صورة نص بديل `alt`.
- [x] الفيديو والصوت يعملان من مجلد `media`.
- [x] عند الضغط على "إرسال الحجز" والحقول فارغة يظهر تنبيه المتصفح ولا يتم الإرسال.
- [x] رقم الهاتف الذي فيه حروف مرفوض (`pattern`)، والوقت بعد العاشرة مساءً مرفوض (`max`).
- [x] بعد ملء النموذج بشكل صحيح ينتقل المتصفح إلى `Thanks.html`، وتظهر البيانات في شريط العنوان.
- [x] **لا يوجد أي CSS أو JavaScript**: لا يوجد `<style>` ولا الخاصية `style` ولا `<script>` ولا ملفات `.css` أو `.js`.
- [x] أداة التحقق الرسمية **W3C Nu Html Checker**: **0 أخطاء**.
  تظهر فقط تنبيهات معلوماتية (info warnings) بأن الخاصيتين `border` و `cellpadding` في الجداول قديمتان وأن البديل هو CSS. استخدمتهما لأن CSS ممنوع في المشروع، وهما خاصيتان من HTML.

**جرّب بنفسك أمام الدكتور:** اضغط بالزر الأيمن على الصفحة ثم "عرض مصدر الصفحة" (أو `Ctrl+U`)، ثم ابحث بـ `Ctrl+F` عن `style` و `script`، ولن تجد أي نتيجة.

## 5. الوسوم المستخدمة وأين

| الوسم أو الخاصية | وظيفته | أين استخدمته |
|---|---|---|
| `<!DOCTYPE html>` | يخبر المتصفح أن الصفحة HTML5 | أول سطر في كل صفحة |
| `<html lang="ar" dir="rtl">` | لغة الصفحة عربية واتجاهها من اليمين لليسار | كل الصفحات |
| `<meta charset="UTF-8">` | لعرض الحروف العربية بشكل صحيح | `<head>` |
| `<meta name="viewport">` | تناسب الصفحة شاشة الجهاز | `<head>` |
| `<title>` | عنوان تبويب المتصفح | `<head>` |
| `<link rel="icon">` | أيقونة الموقع (صورة وليست CSS) | `<head>` |
| `<header>`, `<nav>`, `<main>`, `<section>`, `<footer>` | تقسيم الصفحة إلى أجزاء واضحة | كل الصفحات |
| `<h1>` … `<h3>` | العناوين بالترتيب | كل الصفحات |
| `<p>`, `<br>`, `<hr>` | فقرة، وسطر جديد، وخط فاصل | كل الصفحات |
| `<strong>`, `<em>`, `<small>`, `<code>` | خط عريض، ومائل، وصغير، وكود | النصوص |
| `<img src alt width height>` | عرض صورة مع نص بديل وحجم | الشعار والقائمة والأجواء |
| `<a href>` | رابط | التنقل والأزرار والتواصل |
| `<ul>`, `<ol>`, `<li>` | قائمة نقطية، وقائمة مرقمة، وعنصر القائمة | التنقل، المميزات، خطوات الحجز |
| `<table>`, `<caption>`, `<thead>`, `<tbody>`, `<tr>`, `<th>`, `<td>` | الجداول | قائمة الأسعار وساعات العمل |
| `<figure>`, `<figcaption>` | صورة مع وصفها | قسم الأجواء |
| `<video controls poster>`, `<audio controls>`, `<source>` | تشغيل فيديو وصوت | قسم الأجواء |
| `<details>`, `<summary>` | سؤال يفتح ويغلق بدون JavaScript | الأسئلة الشائعة |
| `<address>` | معلومات التواصل | قسم التواصل |
| `<form>`, `<fieldset>`, `<legend>`, `<label>`, `<input>`, `<select>`, `<option>`, `<textarea>` | النموذج وعناصره | صفحة الحجز |
| `<!-- تعليق -->` | تعليق لا يظهر في المتصفح | في كل الملفات لشرح الأجزاء |

## 6. كيف تعمل الروابط

1. **رابط لصفحة أخرى:** `<a href="Reserve.html">` يفتح ملف `Reserve.html` الموجود في المجلد نفسه (مسار نسبي).
2. **رابط داخل الصفحة:** `<a href="#menu">` ينقل إلى العنصر الذي له `id="menu"`.
3. **رابط لقسم في صفحة أخرى:** `<a href="index.html#menu">` يفتح الرئيسية ثم ينزل إلى قسم القائمة (مستخدم في صفحتي الحجز والشكر).
4. **رابط اتصال وبريد:** `href="tel:0123456789"` يفتح تطبيق الاتصال، و `href="mailto:..."` يفتح تطبيق البريد.
5. **مسارات الصور:** `src="images/logo.png"` تعني: ادخل مجلد `images` ثم افتح `logo.png`.

## 7. كيف يعمل نموذج الحجز بدون JavaScript

- `action="Thanks.html"`: إلى أين يذهب المتصفح عند الإرسال.
- `method="get"`: تُضاف البيانات إلى الرابط بعد علامة `?` بالشكل `name=value&name2=value2`، لذلك تراها في شريط العنوان في صفحة الشكر.
- `name`: اسم كل قيمة في الرابط (مثل `fullname=سارة+أحمد`). الحقل الذي ليس له `name` لا يُرسَل.
- `required`: يمنع الإرسال إذا كان الحقل فارغًا (المتصفح نفسه يتحقق، بدون JavaScript).
- `type="email"`: المتصفح يتحقق من شكل البريد (وجود `@`).
- `pattern="[0-9]{8,15}"`: الهاتف أرقام فقط من 8 إلى 15 رقمًا، و `title` يظهر كتلميح.
- `min="08:00" max="22:00"`: حدود الوقت المسموح.
- `<label for="x">` مرتبط بـ `id="x"`: الضغط على النص يضع المؤشر في الحقل.
- الراديو: كل الخيارات لها `name="seating"` نفسه، فلا يمكن اختيار أكثر من خيار، و `checked` يجعل الخيار الأول محددًا من البداية.
- **لماذا هو تجريبي؟** لأن صفحة HTML ثابتة لا تستطيع حفظ البيانات. الحجز الحقيقي يحتاج لغة خادم (مثل PHP) وقاعدة بيانات، وهذا خارج حدود المشروع.

## 8. أسئلة متوقعة من الدكتور وإجاباتها

**س: لماذا لا يوجد CSS والموقع شكله بسيط؟**
ج: لأن شرط المشروع HTML فقط. استخدمت خصائص HTML نفسها مثل `width` و `height` للصور و `border` و `cellpadding` للجداول، وعناصر مثل `<hr>` و `<fieldset>` لتنظيم الشكل.

**س: كيف ينتقل النموذج إلى صفحة الشكر بدون JavaScript؟**
ج: بالخاصية `action="Thanks.html"` في الوسم `<form>`، فالمتصفح نفسه يفتح هذه الصفحة عند الضغط على زر `submit`.

**س: ما الفرق بين `get` و `post`؟**
ج: `get` تضع البيانات في الرابط فتظهر في شريط العنوان، وتصلح للبيانات غير الحساسة. `post` ترسل البيانات داخل الطلب نفسه فلا تظهر في الرابط، وتُستخدم مع الخادم للبيانات الحساسة أو الكبيرة. اخترت `get` لأنه لا يوجد خادم، ولأنها توضح أن البيانات أُرسلت فعلًا.

**س: ما فائدة `alt` في الصورة؟**
ج: نص بديل يظهر إذا لم تُحمَّل الصورة، وتقرؤه برامج قراءة الشاشة للمكفوفين، ويفيد محركات البحث.

**س: ما فائدة `id`؟ وما الفرق بينه وبين `name`؟**
ج: `id` معرّف فريد للعنصر داخل الصفحة، نستخدمه في الروابط `#about` وفي ربط `label for`. أما `name` فهو اسم القيمة التي تُرسل مع النموذج.

**س: لماذا `dir="rtl"`؟**
ج: لأن المحتوى عربي، فيكون اتجاه الصفحة والجداول والقوائم من اليمين إلى اليسار.

**س: ما الفرق بين `ul` و `ol`؟**
ج: `ul` قائمة نقطية بدون ترتيب (استخدمتها في التنقل والمميزات)، و `ol` قائمة مرقمة مرتبة (استخدمتها في خطوات الحجز).

**س: ما فائدة `thead` و `tbody` و `th`؟**
ج: `thead` يحتوي صف العناوين، و `tbody` يحتوي صفوف البيانات، و `th` خلية عنوان تظهر بخط عريض، و `td` خلية بيانات عادية.

**س: لماذا كتبت `&lt;/&gt;` بدل `</>`؟**
ج: لأن المتصفح يفهم علامتي `<` و `>` على أنهما بداية ونهاية وسم، فكتبتهما بالرموز `&lt;` و `&gt;` لتظهرا كنص.

**س: هل يمكن أن يعمل `details` بدون JavaScript؟**
ج: نعم، `<details>` و `<summary>` من عناصر HTML5، والمتصفح نفسه يفتحهما ويغلقهما.

**س: ما فائدة `<video controls>` و `poster`؟**
ج: `controls` تعرض أزرار التشغيل والإيقاف والصوت، و `poster` صورة تظهر قبل تشغيل الفيديو. والنص داخل `<video>` يظهر فقط إذا كان المتصفح لا يدعم الفيديو.

**س: هل الصور مأخوذة من الإنترنت؟**
ج: لا، كل الصور رسوم توضيحية أصلية خاصة بالمشروع ومحفوظة داخل مجلد `images`، لذلك تعمل بدون إنترنت.

**س: هل بيانات المقهى حقيقية؟**
ج: لا، العنوان والهاتف والأسعار افتراضية، ومذكور ذلك في تذييل الصفحة. البريد ينتهي بـ `.example`، وهو نطاق مخصص للأمثلة.

## 9. تسجيل الفيديو ورفعه

1. افتح `نص-فيديو-الشرح.txt` لتقرأ منه.
2. استخدم برنامج تسجيل شاشة مجانيًا مثل **OBS Studio**، أو أداة تسجيل الشاشة في Windows (`Win + Alt + R` من Xbox Game Bar، أو أداة القصاصة في Windows 11)، وفعّل الميكروفون.
3. ابدأ باسمك ورقمك الجامعي، ثم اتبع الترتيب: فكرة المشروع، ثم استعراض الموقع في المتصفح، ثم شرح الكود (index ثم Reserve ثم Thanks)، ثم تجربة النموذج، ثم الاختبار والخاتمة.
4. اجعل المدة بين 7 و 15 دقيقة (نص الشرح المرفق حوالي 11 دقيقة).
5. ارفع الفيديو على YouTube (اختر "غير مدرج" Unlisted) أو على Google Drive (اختر "أي شخص لديه الرابط يمكنه العرض").
6. انسخ الرابط وضعه في `video link.txt` مكان العبارة `[ضع رابط الفيديو هنا ...]`، واكتب اسمك ورقمك الجامعي.
7. أعد ضغط المجلد `Code-Cafe` بصيغة ZIP وسمِّه باسمك ورقمك الجامعي. في Windows: زر أيمن على المجلد ← إرسال إلى ← مجلد مضغوط.
